# 🛒 MarketNest Marketplace

A full-stack marketplace web application built with modern web technologies.

## 🚀 Live Demo

[Open MarketNest](https://market-nest-marketplace--moazmohmednafea.replit.app/)

## 📌 About The Project

MarketNest is a full-stack marketplace application designed to provide a modern platform for browsing and managing products.

The project focuses on building a scalable architecture with a separate frontend, backend API, and database layer.

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express 5
- TypeScript

### Database
- PostgreSQL
- Drizzle ORM

### Validation & API
- Zod
- OpenAPI

### Package Manager
- pnpm

## ✨ Features

- Product marketplace
- Product browsing
- User authentication
- Backend REST API
- PostgreSQL database
- Data validation
- Responsive user interface
- Structured frontend/backend architecture
